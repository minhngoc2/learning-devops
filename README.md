# Learning DevOps

Ghi chép và bài thực hành về Linux, Bash, Docker, AWS và triển khai ứng dụng bằng Terraform.

> [!NOTE]
> Mỗi thư mục `lessonN/` là một bài độc lập: `cd` vào bài trước khi chạy lệnh. Các bài AWS (10–11, 12, 13 và 12–13) viết bằng tiếng Anh và có `quickstart.md` với lệnh đầy đủ, kết quả mẫu và bước dọn dẹp.

## Bài học

| Bài | Chủ đề |
|-----|--------|
| [Bài 1](lesson1/README.md) | Các lệnh Linux cơ bản |
| [Bài 3](lesson3/README.md) | Bash script kiểm tra dịch vụ |
| [Bài 4](lesson4/README.md) | Docker image cho ứng dụng Python |
| [Bài 5–6](lesson5-6/README.md) | Docker image cho FastAPI theo hướng production |
| [Bài 8](lesson8/README.md) | Thiết kế mạng nội bộ VPC trên AWS |
| [Bài 10–11](lesson10-11/README.md) | Go API + RDS trên ECS Fargate bằng Terraform |
| [Bài 12](lesson12/README.md) | Ứng dụng Nuxt (SPA) với pnpm trên Private S3 và CloudFront HTTPS bằng Terraform |
| [Bài 13](lesson13/README.md) | Go API trên AWS Lambda + API Gateway (HTTP API) bằng Terraform, state trên S3 riêng |
| [Bài 12–13](lesson12-13/README.md) | Python API `GET /users` trên Lambda (1 GB) đọc DynamoDB qua API Gateway, quyền IAM tối thiểu, bằng Terraform với state trên S3 |

> [!CAUTION]
> Các bài AWS tạo tài nguyên có tính phí. Luôn làm theo bước dọn dẹp trong quickstart của từng bài.
