# Archived React demo

This React/Vite counter is retained from the earlier lab. The active lesson uses [Nuxt with pnpm](../nuxt-app/README.md); follow the [quickstart](../quickstart.md) to deploy it.

To run this older demo from `app/`:

```sh
npm ci
npm run dev
```

`npm run lint`, `npm run build`, and `npm run preview` remain available. Vite writes to `dist/`; the Nuxt quickstart upload paths do not apply to this demo.
